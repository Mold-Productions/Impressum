# Mold Productions – Reines Impressum

Eine reine Impressum-Seite für GitHub Pages.

## Enthalten

- `index.html`
- `style.css`
- `script.js`
- `assets/MP_Logo_Weiss.jpeg`

Die wichtigsten Angaben (Inhaber, Anschrift, E-Mail und Telefon) befinden sich direkt im Hauptbereich.

## Vor Veröffentlichung

Alle Platzhalter in `[ ... ]` durch die echten Unternehmensdaten ersetzen.

Welche zusätzlichen Angaben erforderlich sind, hängt insbesondere von der Rechtsform und davon ab, ob das Unternehmen im Firmenbuch eingetragen ist.
